# Welcome to Neural Mastery

Neural Mastery is a single, holistic place to learn everything AI — from the
underlying mathematics up through cutting-edge agent architectures.

Start here: **[The Neural Mastery Roadmap](./roadmaps/overview.md)** — the full learning path, in order.

## What you'll find here

- **[CS Fundamentals for AI Engineers](./cs-fundamentals/overview.md)** — operating systems, concurrency, networking, distributed systems, Linux/Git internals, software engineering practice
- **[Python Engineering for AI](./python-engineering/overview.md)** — OOP & functional Python, decorators & generators, async/concurrency, memory management, packaging, testing, tooling
- **[Mathematics for AI](./mathematics-for-ai/overview.md)** — linear algebra, calculus, probability & statistics, optimization, algorithms & data structures
- **[Machine Learning](./machine-learning/overview.md)** — classical algorithms, common problems and their state-of-the-art solutions
- **[Deep Learning](./deep-learning/overview.md)** — architectures, training techniques, state-of-the-art models
- **[Computer Vision](./computer-vision/overview.md)** — image fundamentals, the vision task taxonomy, modern/multimodal vision
- **[NLP](./nlp/overview.md)** — classical NLP, word embeddings, the task taxonomy underneath modern LLMs
- **[Speech & Audio AI](./speech-audio/overview.md)** — signal processing, spectrograms/MFCCs, ASR, TTS, speaker recognition, diarization
- **[LLMs & GenAI](./llms-genai/overview.md)** — foundation models, training pipelines, prompt engineering, RAG, evaluation, multimodal models
- **[Agents](./agents/overview.md)** — agentic patterns, MCP, A2A, tool use
- **[AI Evaluation](./ai-evaluation/overview.md)** — benchmark design, golden datasets, LLM-as-judge, agent evaluation, human & adversarial evaluation, red teaming
- **[ML System Design](./ml-system-design/overview.md)** — production architectures, scaling, real-world case studies
- **[MLOps](./mlops/overview.md)** — data/experiment versioning, pipelines, containers, Kubernetes, CI/CD, monitoring, drift detection, LLMOps & RAGOps
- **[AI Security](./ai-security/overview.md)** — the OWASP LLM Top 10, prompt injection, model extraction, data poisoning, adversarial examples, AI supply-chain attacks
- **[AI Safety & Alignment](./ai-safety/overview.md)** — RLHF/Constitutional AI, reward hacking, specification gaming, deception, scalable oversight, frontier model safety
- **[Interpretability](./interpretability/overview.md)** — SHAP/LIME, saliency and attention analysis, probing, sparse autoencoders, circuits, mechanistic interpretability
- **[Reinforcement Learning](./reinforcement-learning/overview.md)** — MDPs, Bellman equations, Q-learning, policy gradients, PPO/SAC/TD3, offline RL, and how RLHF fits in
- **[Graph ML](./graph-ml/overview.md)** — graph representation, node/link/graph-level tasks, GNNs, graph embeddings, knowledge graphs, Graph RAG
- **[AI for Science](./ai-for-science/overview.md)** — drug discovery, protein structure prediction, genomics, materials science, PINNs and neural operators
- **[Domain AI Applications](./domain-applications/overview.md)** — healthcare AI in depth, plus finance, semiconductor, cybersecurity, robotics, manufacturing
- **[Research Engineering](./research-engineering/overview.md)** — how to read AI papers, and the paper timeline connecting this site's architectures historically
- **[Build From Scratch](./build-from-scratch/overview.md)** — implement autodiff, attention, a GPT, a vector database, RAG, an agent, and more, yourself
- **[Projects](./projects/overview.md)** — a six-level project ladder from a tiny afternoon build to a frontier capstone
- **[Databases](./databases/overview.md)** — SQL (MySQL, Postgres), vector databases (ChromaDB, etc.), graph databases (Neo4j)
- **[Frameworks](./frameworks/overview.md)** — PyTorch, LangChain, and other tools of the trade
- **[Interview Prep](./interview-prep/overview.md)** — DSA, ML coding, knowledge Q&A, system design, behavioral
- **[Roadmaps](./roadmaps/overview.md)** — structured learning paths tying every topic together
- **[Resources](./resources/open-source-ai-resources.md)** — a running list of external free resources for extra practice
