# Databases Overview

Every AI system needs somewhere to put data — and increasingly, that means three different kinds of database working together, not one.

- **[Relational (MySQL, Postgres)](./relational/overview.md)** — structured data, transactions, ML metadata
- **[Vector Databases](./vector/overview.md)** — embeddings and similarity search, the backbone of RAG
- **[Graph Databases (Neo4j)](./graph/overview.md)** — relationships and multi-hop reasoning, GraphRAG

See the [roadmap](./roadmap.md) for the full ordered path through this section.
