- [Prompt Engineering](./prompt-engineering.md) — few-shot, chain-of-thought, ReAct, prompt injection defenses
- [Retrieval-Augmented Generation (RAG)](./rag.md) — chunking, hybrid search, re-ranking, GraphRAG, evaluation
